# 🟨 Estudos em JavaScript

Repositório pessoal criado para registrar minha evolução nos estudos de **JavaScript**, reunindo exercícios e atividades realizadas durante o acompanhamento das aulas da **Rafaella Ballerini**.

O foco deste repositório é praticar os fundamentos da linguagem e entender como o JavaScript pode ser utilizado junto ao **HTML e CSS** para criar páginas e aplicações web interativas.
